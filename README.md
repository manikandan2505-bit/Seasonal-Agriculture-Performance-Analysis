# Seasonal Agriculture Performance Analysis 🌾

## VOIS AICTE Aug Batch 2026–2027 – Major Project

A data analytics project focused on understanding how agricultural
performance varies across different seasons.

---

## 📌 Project Overview

Agricultural performance can vary across seasons because of changes
in environmental conditions, farming practices, resource availability
and market conditions.

This project analyzes agricultural data to identify meaningful
seasonal patterns, trends, relationships and variations.

---

## 🎯 Objectives

- Explore and understand agricultural data
- Clean and prepare the dataset
- Compare agricultural performance across seasons
- Analyze environmental conditions
- Compare crop performance
- Analyze irrigation methods
- Study water usage and efficiency
- Examine economic performance
- Identify relationships between variables
- Apply statistical analysis
- Generate evidence-based insights and recommendations

---

## 📊 Dataset

The dataset contains agricultural records covering:

- Seasons
- States
- Districts
- Crops
- Irrigation methods
- Environmental conditions
- Agricultural inputs
- Production
- Yield
- Water usage
- Revenue
- Cost
- Profit
- Disease/Pest risk

## 🔬 Analysis Performed

### 1. Data Cleaning
- Missing value analysis
- Duplicate checking
- Data preparation

### 2. Exploratory Data Analysis
- Season distribution
- Crop distribution
- State distribution
- Irrigation distribution

### 3. Seasonal Analysis
- Yield
- Production
- Revenue
- Cost
- Profit
- Water usage
- Water efficiency

### 4. Environmental Analysis
- Rainfall
- Temperature
- Humidity
- Soil conditions
- Sunlight

### 5. Crop Analysis
Comparison of crop performance across seasons.

### 6. Irrigation Analysis
Comparison of irrigation methods based on yield,
profit and water efficiency.

### 7. Statistical Analysis
Kruskal-Wallis tests were used to examine differences
between seasonal distributions.

### 8. Correlation Analysis
Relationships between agricultural, environmental,
resource and economic variables were investigated.

---

## 📈 Key Findings

- Kharif showed the strongest overall agricultural performance.
- Zaid showed weaker economic performance.
- Crop yields varied across seasons.
- Sugarcane showed substantially higher yield than other crops.
- Water efficiency had a strong positive relationship with yield.
- Irrigation performance varied across seasons.
- Seasonal yield and profit distributions showed statistically
  significant differences.
